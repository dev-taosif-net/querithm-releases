First launch

The installers are not code-signed yet, so your OS will ask you to confirm once.

Windows: “Windows protected your PC”

Click More info, then Run anyway.

macOS: “Querithm can’t be opened”
  1. Open the .dmg and drag Querithm to Applications.
  2. Open Querithm once and close the warning.
  3. Go to System Settings → Privacy & Security, scroll down and click Open Anyway.

If macOS says the app “is damaged”, run this in Terminal, then open it again:

xattr -dr com.apple.quarantine /Applications/Querithm.app
Linux: AppImage and packages 
chmod +x Querithm-linux-x64.AppImage
./Querithm-linux-x64.AppImage

sudo apt install ./Querithm-linux-x64.deb   # Debian / Ubuntu
sudo dnf install ./Querithm-linux-x64.rpm   # Fedora / RHEL
Verify your download

Every release has a SHA256SUMS.txt. Compare it with:

sha256sum Querithm-*                     # Linux
shasum -a 256 Querithm-*                 # macOS
Get-FileHash .\Querithm-windows-x64-setup.exe   # Windows PowerShell
